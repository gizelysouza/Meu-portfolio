# Portfólio — Gizely Souza

Site pessoal para apresentação profissional em oportunidades de estágio em Front-end com foco em UX/UI.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Como visualizar
1. Extraia o arquivo ZIP.
2. Abra a pasta `portfolio-gizely-souza`.
3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um servidor.

## Antes de publicar
- No `index.html`, procure `SEU_EMAIL_AQUI` e substitua pelo seu endereço de e-mail.
- Adicione links reais do seu GitHub e LinkedIn, se quiser incluí-los.
- Confira os textos dos projetos e inclua imagens reais dos protótipos/telas quando estiverem disponíveis.
- O link do projeto Clima em Chamas já está configurado.

## Publicação
Você pode publicar gratuitamente pelo GitHub Pages, Netlify ou Vercel. Basta enviar os três arquivos principais (`index.html`, `style.css` e `script.js`) para o serviço escolhido.
